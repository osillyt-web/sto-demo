# АвтоТочка — сайт СТО/детейлинг + админ-панель (демо для портфолио)

Готовый сайт, который можно показывать клиенту и брать в работу как основу.
Без внешних зависимостей: только Python 3.11+ и стандартная библиотека. База — SQLite.

## Статус работ

Актуальный чек-лист доработок (что сделано, чем проверено, что осталось) —
**[CHECKLIST.md](CHECKLIST.md)**. Он же используется как приёмка перед показом клиенту.

## Запуск

```
start.bat
```
или
```
python server.py
```

- Сайт: <http://127.0.0.1:8000/>
- Админка: <http://127.0.0.1:8000/admin>
- Демо-пароль: `admin123` (переменная `ADMIN_PASSWORD`), порт — `PORT`

`start.bat` сам находит Python, проверяет занятость порта и открывает браузер.
Если сервер уже запущен — просто открывает сайт.

## Что внутри сайта

- Hero с фотографией сервиса, оффером, карточкой свободного слота и ключевыми цифрами.
- Полоса преимуществ: фиксированная цена, фото-отчёт, гарантия, запчасти.
- Услуги из базы: иконка, цена, описание, кнопка «Записатись» с автоподстановкой в форму.
- **Галерея работ** — 6 реальных фото, лайтбокс по клику, подписи «услуга · авто».
- **«До / після»** на фотографиях: перетаскиваемая смужка (pointer events + клавиатура).
- **Калькулятор стоимости**: услуги + класс авто с коэффициентом 1.0–1.5. Класс
  выбирается четырьмя карточками с радиокнопками (не выпадающим списком) — видны все
  варианты сразу, работает с клавиатуры, на мобильном идёт в одну колонку.
  Живой расчёт диапазона, кошторис уходит в заявку вместе с выбранными услугами.
- Этапы работ, прайс из базы, отзывы с рейтингом, FAQ-аккордеон.
- **Онлайн-запись по слотам**: день выбирается кнопками (14 дней вперёд, сегодня/завтра
  подписаны, воскресенье закрыто), затем — свободная година. Вместимость часа
  настраивается (по умолчанию 2 авто), занятые и прошедшие часы недоступны, заняли
  последнее место — сервер отвечает «Цей час щойно зайняли».
- Форма записи: имя, телефон (**маска +380 XX XXX XX XX**), услуга, авто, дата и час
  из слотов, комментарий, **галочка согласия с политикой** (без неё заявка не принимается),
  honeypot, клиентская валидация и понятные сообщения.
- **Кнопки мессенджеров** (Telegram, Viber, WhatsApp) в шапке, в блоке контактов и в
  мобильном меню; все ссылки правятся в админке.
- **«Передзвоніть за 30 секунд»** — форма обратного звонка из одного поля.
- **Блок «Гарантія і прозорість»** — 4 карточки: гарантия 12 месяцев, цена до работ,
  фото-отчёт, подмена авто. Отзывы с оценкой и ссылкой на Google.
- **Страница `/cases`** — портфолио из трёх кейсов (сайт СТО, Telegram-бот учёта ГСМ,
  Android-застосунок VoiceReader) по схеме задача → решение → результат.
- **Источник заявки**: UTM-метки и переход сохраняются в сессии и уходят в заявку.
- Контакты, мессенджеры, карта (кликабельная ссылка на Google Maps — без медленного
  iframe, страница грузится мгновенно), футер.
- Мобильная панель действий: после первого экрана снизу появляется одна главная кнопка
  «Записатись на сервіс» + кнопка-иконка звонка (48×48, отступы 16 px, safe-area).
  Панель прячется у формы записи и на первом экране, где та же кнопка есть в шапке.
  На компьютере панели нет — там работают кнопка в шапке и форма.
- Бургер-меню, адаптив от 360px.
- Плавный скролл собственной анимацией (не зависит от системной настройки
  `prefers-reduced-motion`), отменяется при прокрутке колесом или касании.

## Что внутри админки

- Статистика: всего заявок, новых, за сегодня, доля новых.
- Заявки: фильтр (усі / нові / опрацьовані), поиск по имени, телефону, авто и услуге.
- Статус заявки, **нотатка менеджера** (автосохранение), удаление.
- **Экспорт CSV** (разделитель `;`, BOM — Excel открывает кириллицу без искажений).
- Услуги: правка названия, цены, базы для калькулятора и описания; вкл/выкл показ
  на сайте, порядок, удаление, добавление.
- **Аналітика**: воронка «відкрили сайт → калькулятор → почали заявку → надіслали»,
  конверсия, топ услуг, график заявок по дням. Свой счётчик, без Google Analytics.
- **Сповіщення в Telegram**: токен бота + chat_id, кнопка «Надіслати тест»,
  статус «увімкнено/вимкнено». Токен хранится в базе и в интерфейсе показывается
  только хвостом (`…AAAAAA`), в API не отдаётся.
- **Завантаження записів** — недельный календарь: по каждому дню и часу видно, сколько авто
  занято из доступных, ниже — список записей с телефонами. Переключение недель.
- **Контакти, слоти й відгуки** — телефон, адреса, график, ссылки на мессенджеры, ссылка
  на отзывы Google и оценка для сайта правятся в админке и сразу меняют сайт; там же
  вместимость часа и список рабочих часов.
- **Смена пароля** прямо в панели: PBKDF2-SHA256, 200 000 итераций, соль на пароль;
  после смены все сессии сбрасываются.
- Безопасность: сессия в HttpOnly-cookie (SameSite=Lax), лимит неудачных входов,
  проверка Origin на изменяющих запросах, honeypot и лимит частоты на форме,
  CSP, X-Frame-Options, nosniff, Referrer-Policy.

## Технические детали, которые обычно забывают

| Что | Как сделано |
|---|---|
| Сжатие | gzip для HTML/CSS/JS (экономия ~70%) |
| Кеш статики | `?v=<mtime файла>` — правки CSS/JS сразу видны клиенту |
| SEO | title, description, canonical, OG/Twitter, `robots.txt`, `sitemap.xml`, `favicon.svg`, `apple-touch-icon` |
| Микроразметка | JSON-LD `AutoRepair` + `FAQPage` |
| Юридическое | `/privacy` — политика конфиденциальности (данные, сроки, права, cookie) |
| Аналитика | свои события `view / calc_used / form_start / lead_sent` в SQLite |
| Фото | WebP, два размера на кадр, `srcset` (на телефоне hero 41 КБ вместо 182 КБ), `loading="lazy"`, явные `width/height` |
| Ошибки порта | на Windows `allow_reuse_address=False` — иначе два сервера делят порт 8000 |

## Проверено прогоном

```
python test_flow.py
```

**72 проверки**: рендер главной и услуг из БД, калькулятор, валидация формы и согласия,
honeypot, вход/выход, закрытые API, кириллица в БД, кошторис, фильтры и поиск, CSV,
правка и добавление услуг, блокировка чужого Origin, страница политики, robots/sitemap,
favicon, CSP и X-Frame-Options, микроразметка, alt у фото, gzip, приём событий аналитики,
закрытость аналитики и настроек; **слоты** (14 дней, вместимость часа, отказ на третьем
авто, занятость в календаре), **UTM в заявке**, обратный звонок, страница `/cases`,
человеческая 404, контакты из админки на сайте. Прогон **не портит демо-данные**.

Отдельно проверено в браузере: маска телефона (`0501234567`, `380671112233`, вставка
готового номера), перетаскивание «до/після», лайтбокс, воронка событий, сохранение
настроек Telegram и корректный отказ при неверном токене, смена пароля.

## Чего нет (нужно доделать до боевого запуска)

1. HTTPS и домен — на VPS: nginx + Let's Encrypt, `python server.py` под systemd.
2. Ежедневный бэкап базы (`data/sto.db`) — cron + копия в облако.
3. Выгрузка занятости мастера в Google Calendar — сейчас календарь живёт в админке.
4. Реальные фото и цены клиента вместо демо-контента.
5. Приём оплаты/предоплаты — если клиент захочет.

## Публикация

**Демо за 5 минут, бесплатно:** Render, через `render.yaml` — пошагово в [RENDER.md](RENDER.md).
Даёт ссылку вида `https://sto-demo.onrender.com`; ограничения бесплатного тарифа
(засыпание, обнуление базы) там же.

**Боевой запуск:** VPS от $5/мес: `python server.py` под systemd, nginx как reverse proxy,
Let's Encrypt. Домен `.com.ua` ~300 грн/год.

## Важно про выбор технологии

Этот стек — для нестандартных задач: калькулятор, личный кабинет, запись со слотами,
интеграции, боты. Типовой сайт «под ключ» малому бизнесу выгоднее отдавать на
WordPress + Elementor: клиент сможет нанять любого подрядчика, поставить плагины и
сам менять контент. Кастомный код оправдан, когда логика не собирается из плагинов —
как здесь: калькулятор с классами авто, воронка, живая админка.

## Структура

```
server.py             маршруты, БД, авторизация, рендер, аналитика (stdlib)
templates/index.html  главная
templates/admin.html  админка (заявки, услуги, аналитика, Telegram, пароль)
templates/login.html  вход
templates/privacy.html политика конфиденциальности
templates/cases.html  портфолио: три кейса
templates/404.html    страница «не знайдено»
static/style.css      тема сайта
static/app.js         слоты записи, калькулятор, слайдер, лайтбокс, маска, UTM, аналитика
static/admin.css      стили админки
static/admin.js       заявки, календарь загрузки, услуги, контакты, аналитика
static/img/           фото WebP (hero, галерея, мастер), favicon, иконки
test_flow.py          72 проверки
shots/                скриншоты для портфолио
data/sto.db           база (создаётся при первом запуске)
data/auth.json        хеш пароля админки (создаётся при первом запуске)
backup_v2/            копия предыдущей версии (до фото/аналитики)
```
