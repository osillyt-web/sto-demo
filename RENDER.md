# Публикация демо на Render (бесплатно)

Даёт ссылку вида `https://sto-demo.onrender.com`, которую можно отправлять клиенту.
Сайт живёт на бесплатном тарифе: засыпает после 15 минут без посетителей,
первый заход после сна грузится 20–40 секунд.

## Что нужно

1. Аккаунт Render — вход через GitHub (кнопка **Get Started → GitHub**).
2. Доступ Render к репозиторию `osillyt-web/sto-demo`: при первом подключении
   Render попросит установить GitHub App и дать доступ к этому репозиторию.

## Шаги

1. <https://dashboard.render.com/> → **New +** → **Blueprint**.
2. Выбрать репозиторий **sto-demo** (ветка `main`).
3. Render прочитает `render.yaml` и предложит создать сервис **sto-demo**.
4. В поле **ADMIN_PASSWORD** задать свой пароль админки (не оставлять `admin123`).
5. **Apply / Create** — сборка занимает 1–3 минуты.
6. Готовая ссылка появится вверху страницы сервиса.

## Что важно знать про бесплатный тариф

| Ограничение | Следствие для демо |
|---|---|
| Засыпание через 15 минут | первый заход «холодный», 20–40 с |
| Диск не сохраняется | заявки и правки цен обнуляются при перезапуске: для показа это нормально, для клиента нужен платный диск или VPS |
| 750 часов в месяц | хватает на один сервис, работающий круглосуточно |

## Постоянное хранение (если понадобится)

В Render: **Disks → Add Disk**, mount path `/var/data`, затем в переменных среды
добавить `DATA_DIR=/var/data`. Диск платный ($0,25 за ГБ в месяц) и доступен
только на платных тарифах сервиса.

## Обновление сайта

Любой `git push` в `main` запускает пересборку и перезапуск автоматически.

## Проверка после деплоя

1. Открыть ссылку с телефона (мобильная панель, галерея, «до/після»).
2. Отправить тестовую заявку — она должна появиться в `/admin`.
3. В админке: **Сповіщення в Telegram** → вставить токен бота и chat_id → «Надіслати тест».
4. Сменить пароль админки в разделе **Пароль адміністратора**.
