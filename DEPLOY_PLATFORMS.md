# Выбор платформы для сайта «АвтоКрапка»

Документ собран по замерам проекта и официальным условиям платформ на 13.11.2026.

## 1. Требования, измеренные на этом сайте

| Параметр | Измерено | Как измерено |
|---|---|---|
| Память процесса | **5,2 МБ** (Windows), с Python-рантаймом на Linux около 30–40 МБ | запуск с пустой папкой `data`, замер WorkingSet |
| Время старта | **1,03 с** с нуля, 0,51 с повторно | до первого ответа `/api/health` |
| Пропускная способность | **62,8 запроса/с** в одном процессе | 120 запросов к `/` и `/order` |
| Зависимости | **нет**, только стандартная библиотека Python | `requirements.txt` пуст |
| Версия Python | работает на **3.12 и 3.13** | прогон на Linux (Kali, Python 3.13.12) |
| Порт | берётся из `PORT`, слушает `HOST=0.0.0.0` | проверено запуском с переменными |
| Запись на диск | `data/` — база `sto.db` + `auth.json`, `backups/` — резервные копии | после старта в `data/` появились 2 файла |
| Исходящий интернет | нужен для Telegram-уведомлений и SMTP | `urllib` к внешним API |
| Размер проекта | 100 МБ всего, из них сайт — около **5 МБ** (статика 2,1 МБ, шаблоны 0,1 МБ) | `du` без venv и артефактов |

**Главный вывод замера:** сайт очень лёгкий. Ограничения бесплатных тарифов упираются не в память и не в скорость, а в **постоянный диск** и **сон инстанса**.

Проверка потери данных: после удаления `data/` и перезапуска база создалась заново (32 КБ), **заявок в ней 0**. Значит на платформе без постоянного диска заявки клиентов будут теряться при каждом перезапуске.

## 3. Что рекомендую

**Для показа заказчикам и первых заявок — Northflank Sandbox.** Единственный найденный бесплатный вариант, который одновременно: не засыпает, даёт постоянный диск под SQLite и не требует карты. Сайт + Telegram-бот укладываются в два бесплатных сервиса.

**Для боевого сайта клиента** — либо тот же Northflank с оплатой по факту (сверх кредита копейки), либо VPS: Oracle Always Free (бесплатно, но с картой и настройкой) или украинский хостинг 150–250 грн/мес с постоянным диском.

**Не рекомендую:** Render Free для боевого (теряет заявки), Cloud Run (нужна внешняя база), PythonAnywhere (нет произвольного исходящего интернета — не будет Telegram), Railway Free ($1 кредита хватает на дни).

## 4. Как развернуть (после регистрации аккаунта)

В проекте уже готово:

- `Dockerfile` — образ на `python:3.13-slim`, `PORT` из окружения, тома `/app/data` и `/app/backups`;
- `.dockerignore` — в образ не попадают venv, база, скриншоты, тесты;
- `render.yaml` — конфигурация для Render (free, frankfurt, healthcheck);
- `tools/smoke_deploy.py` — проверка развёрнутого сайта по внешнему адресу.

### Northflank (пошагово)

1. Регистрация на northflank.com (можно через GitHub).
2. **Create project** → Create service → **Build from repository** (репозиторий `osillyt-web/...`) или **Deploy from Dockerfile**.
3. Порт сервиса: `8000`, тип — HTTP.
4. Переменные окружения: `PORT=8000`, `ADMIN_PASSWORD=<свой пароль>`, `HOST=0.0.0.0`; при необходимости SMTP-настройки.
5. **Volumes**: создать диск и примонтировать в `/app/data` (это и есть сохранение заявок).
6. Deploy. После сборки платформа даст адрес вида `*.northflank.app`.
7. Проверка: `python tools/smoke_deploy.py https://адрес` — должно быть «ПРОЙДЕНО».

### Render (пошагово)

1. Регистрация на render.com через GitHub.
2. New → Web Service → подключить репозиторий, Render прочитает `render.yaml`.
3. `ADMIN_PASSWORD` задать в панели (в репозитории его нет).
4. Для сохранения заявок нужен платный план Starter ($7) + диск на `/app/data`; на Free диск не подключается.
