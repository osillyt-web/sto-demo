# АвтоКрапка — сайт СТО/детейлинг + админ-панель (демо для портфолио)

Готовый сайт, который можно показывать клиенту и брать в работу как основу.
Без внешних зависимостей: только Python 3.11+ и стандартная библиотека. База — SQLite.

## Статус работ

Актуальный чек-лист доработок (что сделано, чем проверено, что осталось) —
**[CHECKLIST.md](CHECKLIST.md)**. Он же используется как приёмка перед показом клиенту.

### Портфолио и каналы связи (11.11.2026)

- Страница `/order` предлагает сайт для СТО и разработку Telegram-бота для бизнеса; в контактах стоят email, Viber, WhatsApp и Telegram **@lumyrix**. Это контакты владельца портфолио, не демонстрационного СТО.
- Кнопка Telegram сейчас ведёт в личный чат владельца; полноценный Telegram-бот ещё не написан. Изменения пока локальные, на публичный хостинг не выкладывались.
- Telegram- и WhatsApp-боты **не написаны**: сначала нужно согласовать функции, диалог и стек. WhatsApp Cloud API имеет бесплатную квоту для сервисных сообщений, но другие категории тарифицируются; актуальные детали и блокирующие шаги — в `CHECKLIST.md`.
- Viber-ссылка ведёт в существующий бизнес-чат, а не в бота. Новый Viber-бот пока не планируется из-за фиксированной платы и тарификации сообщений; см. источники в `CHECKLIST.md`.

## Эксплуатация

### Форма заявки на /order (13.11.2026)

- Блок «Зв'язатися письмово» — форма из четырёх полей: имя, email или телефон, направление (сайт / бот / оба), детали. Согласие на обработку данных обязательно, ссылка на `/privacy`.
- Заявка сохраняется в базу (`leads.kind='order'`, источник «Сторінка замовлення», в админке метка «з форми»), дублируется в Telegram и, если настроен SMTP, уходит письмом на `ORDER_EMAIL_TO`.
- Почта включается переменными окружения в `.env`: `SMTP_HOST`, `SMTP_PORT` (587), `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`, `ORDER_EMAIL_TO`; для сервера без STARTTLS — `SMTP_TLS=0`. Без `SMTP_HOST` форма работает, но письмо не отправляется, в `data/errors.log` появляется `order_email: ... SMTP не налаштовано`.
- Для ящиков Gmail/Outlook нужны записи SPF и DKIM у домена отправителя, иначе письма попадают в спам.
- Защита: скрытое поле-ловушка `company`, проверка контакта на сервере (email или 9–15 цифр), лимит частоты, ограничение длины (имя 80, контакт 80, детали 800).
- Проверено: 290 автопроверок (12 новых для формы), отправка из Chromium/Firefox/WebKit, axe — 0 нарушений, горизонтального переполнения нет на 320–1920.

### Резервные копии и здоровье

- Резервные копии: `backups/sto-YYYYMMDD-HHMMSS.db`, хранятся 7 последних, снимаются при старте
  (если последней нет или она старше 20 часов) и ежедневно в 03:00. Вручную — `python server.py --backup`.
- Health-check для сторожа: `GET /api/health` → `{"ok": true, "db": "ok", "leads": 4, "backup_age_h": 2.5}`.
- Журнал действий администратора и размер базы — в админке, панель «Стан системи».
- Ошибки пишутся в `data/errors.log`.
- Пароль админки: минимум 10 символов, буквы и цифры; демо-пароль подсвечивается баннером.
- Переменные окружения читаются из `.env` (шаблон — `.env.example`).

## Что внутри сайта

- Hero с фотографией сервиса, оффером, карточкой свободного слота и ключевыми цифрами.
- Полоса преимуществ: фиксированная цена, фото-отчёт, гарантия, запчасти.
- Услуги из базы: иконка, цена, описание, кнопка «Записатись» с автоподстановкой в форму.
- **Галерея работ** — 6 реальных фото, лайтбокс по клику, подписи «услуга · авто».
- **«До / після»** на фотографиях: перетаскиваемая смужка (pointer events + клавиатура).
- **Калькулятор стоимости**: услуги + класс авто с коэффициентом 1.0–1.5. Класс
  выбирается четырьмя карточками с радиокнопками (не выпадающим списком) — видны все
  варианты сразу, работает с клавиатуры, на мобильном идёт в одну колонку.
  Живой расчёт диапазона, кошторис уходит в заявку вместе с выбранными услугами.
- Этапы работ, прайс из базы, отзывы с рейтингом, FAQ-аккордеон.
- **Онлайн-запись по слотам**: день выбирается кнопками (14 дней вперёд, сегодня/завтра
  подписаны, воскресенье закрыто), затем — свободная година. Вместимость часа
  настраивается (по умолчанию 2 авто), занятые и прошедшие часы недоступны, заняли
  последнее место — сервер отвечает «Цей час щойно зайняли».
- Форма записи: имя, телефон (**маска +380 XX XXX XX XX**), услуга, авто, дата и час
  из слотов, комментарий, **галочка согласия с политикой** (без неё заявка не принимается),
  honeypot, клиентская валидация и понятные сообщения.
- **Кнопки мессенджеров** (Telegram, Viber, WhatsApp) в шапке, в блоке контактов и в
  мобильном меню; все ссылки правятся в админке.
- **«Передзвоніть за 30 секунд»** — форма обратного звонка из одного поля.
- **Блок «Прозорість»** — 3 карточки: цена до работ, фото-отчёт и подмена авто.
  Отзывы с оценкой и ссылкой на Google.
- **Страницы услуг** `/services/<slug>` — шесть отдельных страниц с ценами по классам авто,
  составом работ, «что не входит», FAQ и разметкой `Service` + `BreadcrumbList` + `FAQPage`.
  Список — `/services`.
- **Страницы марок** `/brands/<slug>` — шесть марок (Volkswagen, Toyota, Skoda, BMW, Renault,
  Nissan) с моделями и ссылками на услуги. Список — `/brands`.
- **Напоминание о записи** — у каждой заявки свой адрес `/r/<token>`, где клиент видит дату,
  час и адрес и может нажать «Підтвердити» или «Скасувати». Владелец копирует готовый текст
  напоминания из админки (кнопка 🔔) и отправляет в Viber/Telegram. Фоновый обработчик раз
  в 15 минут находит записи на ближайшие 26 часов и пишет в Telegram.
- **Просьба про отзыв** — кнопка ★ у выполненной заявки копирует текст со ссылкой на отзывы;
  инструкция для владельца — `GOOGLE_BUSINESS.md`.
- **Страница `/cases`** — портфолио из трёх кейсов (сайт СТО, Telegram-бот учёта ГСМ,
  Android-застосунок VoiceReader) по схеме задача → решение → результат.
- **Источник заявки**: UTM-метки и переход сохраняются в сессии и уходят в заявку.
- Контакты, мессенджеры, карта (кликабельная ссылка на Google Maps — без медленного
  iframe, страница грузится мгновенно), футер.
- Мобильная панель действий: после первого экрана снизу появляется одна главная кнопка
  «Записатись на сервіс» + кнопка-иконка звонка (48×48, отступы 16 px, safe-area).
  Панель прячется у формы записи и на первом экране, где та же кнопка есть в шапке.
  На компьютере панели нет — там работают кнопка в шапке и форма.
- Бургер-меню, адаптив от 360px.
- Плавный скролл собственной анимацией (не зависит от системной настройки
  `prefers-reduced-motion`), отменяется при прокрутке колесом или касании.
- **Отзывы**: на главной — средняя оценка, три свежих отзыва и кнопки «Читати всі N
  відгуків» / «Залишити відгук»; блок не растёт при любом количестве отзывов.
  Вся история живёт на отдельной странице `/reviews`: сетка по 12 штук, фильтр по
  звёздам, страницы. Из базы берётся только одна страница, поэтому и при 300 отзывах
  страница весит ~10 КБ и открывается за 4 мс. Там же — форма «Залишити відгук»
  (имя, марка авто, звёзды, текст, согласие на публикацию) с защитой от спама:
  скрытое поле-ловушка, не больше 3 отзывов в час с одного адреса, запрет ссылок
  в тексте. Пока ни один отзыв не одобрен, в блоке показываются демонстрационные
  с честной пометкой — как только владелец одобряет первый настоящий, демо уходит само.

## Что внутри админки

- Статистика: всего заявок, новых, за сегодня, доля новых.
- Заявки: фильтр (усі / нові / опрацьовані), поиск по имени, телефону, авто и услуге.
- Статус заявки, **нотатка менеджера** (автосохранение), удаление.
- **Экспорт CSV** (разделитель `;`, BOM — Excel открывает кириллицу без искажений).
- Услуги: правка названия, цены, базы для калькулятора и описания; вкл/выкл показ
  на сайте, порядок, удаление, добавление.
- **Аналітика**: воронка «відкрили сайт → калькулятор → почали заявку → надіслали»,
  конверсия, топ услуг, график заявок по дням. Свой счётчик, без Google Analytics.
- **Обнуление статистики** — кнопка «Очистити статистику» в блоке «Аналітика сайту»
  (рядом с «Оновити»). Спрашивает подтверждение, затем удаляет все записи о заходах:
  воронку, топ услуг, график по дням. **Заявки клиентов не затрагиваются** — они в отдельном
  списке и остаются на месте. Действие необратимое. Доступно только владельцу: без сессии
  админки сервер отвечает 401, кнопка постороннему не показывается.
  Зачем: начать считать статистику с чистого листа (например, после тестовых заходов
  или перед стартом рассылки). Очистка пишется в журнал действий админки.
- **Сповіщення в Telegram**: токен бота + chat_id, кнопка «Надіслати тест»,
  статус «увімкнено/вимкнено». Токен хранится в базе и в интерфейсе показывается
  только хвостом (`…AAAAAA`), в API не отдаётся.
- **Завантаження записів** — недельный календарь: по каждому дню и часу видно, сколько авто
  занято из доступных, ниже — список записей с телефонами. Переключение недель.
- **Контакти, слоти й відгуки** — телефон, адреса, график, ссылки на мессенджеры, ссылка
  на отзывы Google и оценка для сайта правятся в админке и сразу меняют сайт; там же
  вместимость часа и список рабочих часов.
- **Відгуки з сайту (модерація)** — отзывы, присланные посетителями со страницы
  `/reviews`, попадают в админку со статусом «на перевірці» и на сайте не видны.
  Владелец жмёт «Опублікувати» — отзыв появляется в блоке на главной и на `/reviews`;
  «Зняти з публікації» возвращает в pending, «Видалити» убирает навсегда. Все действия
  пишутся в журнал. Без сессии админки сервер отвечает 401.
  Зачем модерация: без неё в блоке отзывов через месяц будет реклама и спам.
- **Кнопка «Догори»** в админке: появляется после прокрутки, плавно поднимает наверх, уважает `prefers-reduced-motion`.
- **Показ пароля**: кнопка-глаз в полях пароля (вход и смена пароля), по Esc снова скрывает;
  тач-зона 44 px на телефоне, состояние передаётся скринридеру через `aria-pressed`.
- **Смена пароля** прямо в панели: PBKDF2-SHA256, **600 000 итераций** (рекомендация OWASP), своя соль на пароль; старые хеши поднимаются до новой стоимости при первом входе;
  после смены все сессии сбрасываются.
- Безопасность: сессия в HttpOnly-cookie (SameSite=Lax), лимит неудачных входов,
  проверка Origin на изменяющих запросах, honeypot и лимит частоты на форме,
  CSP, X-Frame-Options, nosniff, Referrer-Policy.

## Технические детали, которые обычно забывают

| Что | Как сделано |
|---|---|
| Адреса | лишние кавычки/точки в конце адреса срезаются и уводятся 301 на чистый путь (`/admin»` → `/admin`) |
| Эксплуатация | резервные копии базы (7 последних, ежедневно 03:00 + при старте), `--backup` вручную, журнал действий администратора, `data/errors.log`, health-check `/api/health` |
| Сжатие | gzip для HTML/CSS/JS (экономия ~70%) |
| Кеш статики | `?v=<mtime файла>` — правки CSS/JS сразу видны клиенту |
| Микроразметка | JSON-LD `AutoRepair` + `FAQPage` |
| Юридическое | `/privacy` — политика конфиденциальности (данные, сроки, права, cookie) |
| Аналитика | свои события `view / calc_used / form_start / lead_sent` в SQLite |
| SEO | `title`, `description`, `canonical`, OG/Twitter на каждой странице, `robots.txt`, `sitemap.xml` из 17 адресов, `favicon.svg`, `apple-touch-icon`, JSON-LD: AutoRepair, Service, BreadcrumbList, FAQPage, CollectionPage |
| Фото | WebP, два размера на кадр, `srcset` (на телефоне hero 41 КБ вместо 182 КБ), `loading="lazy"`, явные `width/height` |
| Ошибки порта | на Windows `allow_reuse_address=False` — иначе два сервера делят порт 8000 |

Для браузерных проверок установлено отдельное локальное окружение `pwenv` (Python 3.12, Playwright 1.65.0; Chromium, Firefox и WebKit). Окружение исключено из Git. Если его потребуется пересоздать:

```bat

uv pip install --python pwenv\Scripts\python.exe playwright
pwenv\Scripts\python.exe -m playwright install chromium firefox webkit
```

Запуск проверок:

```bat
pwenv\Scripts\python.exe tools\axe_check.py
pwenv\Scripts\python.exe tools\cross_browser_check.py
```

## Важно про выбор технологии

Этот стек — для нестандартных задач: калькулятор, личный кабинет, запись со слотами,
интеграции, боты. Типовой сайт «под ключ» малому бизнесу выгоднее отдавать на
WordPress + Elementor: клиент сможет нанять любого подрядчика, поставить плагины и
сам менять контент. Кастомный код оправдан, когда логика не собирается из плагинов —
как здесь: калькулятор с классами авто, воронка, живая админка.
