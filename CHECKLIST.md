## Как проверить самому

```
python server.py          # сайт: http://127.0.0.1:8000/  админка: /admin
python test_flow.py       # 72 проверки, должен быть код 0
```

Ручные сценарии:
1. Форма записи: выбрать день → час → отправить; повторить дважды на один час,
   третий раз должен прийти отказ «Цей час щойно зайняли».
2. Админка → «Завантаження записів»: занятые часы подсвечены, ниже записи.
3. Админка → «Контакти, слоти й відгуки»: изменить телефон → сохранить → Ctrl+F5 на сайте.
4. Открыть `/cases`, `/nope` (404), проверить на телефоне 390 px.
